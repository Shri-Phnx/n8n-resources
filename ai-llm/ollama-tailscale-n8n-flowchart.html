② Setup Steps
🔒 Tailscale
1
Install Tailscale on Windows laptop. Sign in with Google account at tailscale.com/download.
↓
2
Install on Hostinger VPS:curl -fsSL https://tailscale.com/install.sh | shsudo tailscale up
↓
3
Sign in with the SAME Google account when the login URL appears on VPS.
↓
4
Verify both devices visible:tailscale status✅ Must see 100.94.10.77 AND 100.110.9.89
💻 Ollama (Windows)
1
Download and install Ollama from ollama.com. Binds to 127.0.0.1 by default.
↓
2
Set binding permanently (Admin CMD):setx OLLAMA_HOST "0.0.0.0" /M⚠ setx affects future sessions only. Restart Ollama after.
↓
3
Add Windows Firewall inbound rule via wf.msc: TCP port 11434, all 3 profiles (Domain, Private, Public).
↓
4
Pull models:ollama pull mistralollama pull phi4-miniollama pull qwen3:4bollama pull gemma4:e4b
↓
5
Verify binding:netstat -ano | findstr 11434✅ Must show 0.0.0.0:11434 not 127.0.0.1
🖥️ n8n Credential
1
Open n8n on Hostinger VPS. Go to Settings → Credentials → New Credential.
↓
2
Search for and select Ollama as the credential type.
↓
3
Set Base URL:http://100.94.10.77:11434Leave API Key blank.
↓
4
Name the credential:Ollama Local (Tailscale)Save it.
↓
5
n8n auto-tests the connection.✅ Expect: Connection tested successfully
